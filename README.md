# Hotel Reservation System

A simple console-based Hotel Reservation System developed using Java.

## About the Project

The Hotel Reservation System allows users to view available hotel rooms, book rooms, check booking details, and cancel reservations through a menu-driven interface.

This project demonstrates the use of Java fundamentals, arrays, methods, loops, conditional statements, and user input handling.

## Features

* View available rooms
* Book a hotel room
* Enter customer details
* Calculate room charges based on the number of days
* View booking details
* Cancel room reservations
* Menu-driven console interface

## Technologies Used

* Java
* Java Scanner
* Arrays
* Methods
* Loops and conditional statements

## How to Run

### Prerequisites

Install Java JDK on your computer.

### Compile the Program

```bash
javac HotelReservationSystem.java
```

### Run the Program

```bash
java HotelReservationSystem
```

## How to Use

1. Run the program.
2. Select an option from the menu.
3. View available rooms.
4. Enter the room number to book.
5. Provide customer name and number of days.
6. View or cancel bookings using the menu.
